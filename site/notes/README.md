# Editorial notes

The page is intentionally written as a field journal rather than a generic feature catalogue.

Keep future posts in the format:

1. scene or question;
2. observed failure or discovery;
3. root cause;
4. engine change;
5. before/after evidence;
6. remaining uncertainty.

Do not invent device, preset, capture-mode, performance, or image-quality claims. Use supplied field images and preserve the boundary between simulated infrared and real sensor capture.
