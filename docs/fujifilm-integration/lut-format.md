# LUT residual contract

A residual LUT is optional and must not be the primary look model. The analytic tone, density, and protection stages remain authoritative.

The first safe fallback is identity behavior when an asset is missing or invalid. GLES 2-compatible tiled 2D sampling is preferred before any GLES 3 3D texture path. LUT sampling must clamp coordinates, preserve alpha/geometry, and be versioned with the renderer/look schema.

No proprietary Fujifilm LUT, firmware extraction, or copied camera asset is permitted.
